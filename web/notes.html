RESEARCH DESK
The research you write, kept as plain text files in the desk's own data/notes folder, one file per note. A note names the listings it is about and the project it belongs to, and links to other notes with [[double brackets]], so a company page shows every note about it, a project shows every name and note inside it, and one note leads to the next. Open the folder in Obsidian or any editor and the same notes are there; your AI agent reads and writes them too.
