RESEARCH DESK

The terminal door

This plugin lets the Ask box answer through the coding agent already on this computer, so you need no separate AI key. Open the Ask box on any screen and pick Terminal in the small picker at the top; the question goes to the agent with the screen's own numbers and your notes, exactly as it would go to a provider, and the answer comes back into the box, where Save as note and Save as task work as usual.

checking which agent is on this computer…

The agent is told to answer from the data and nothing else: no commands, no file edits, no permissions. It reaches its own provider with its own login, which is the one thing this door talks to.
