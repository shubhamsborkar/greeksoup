RESEARCH DESK

An example plugin

This page is an example, here for anyone who wants to write a plugin of their own. If you did not mean to build one, you do not need it: open Settings, then Plugins, and remove it; nothing else changes.

This screen is a plugin: one HTML file in data/research/plugins/hello/, in the sidebar because plugin.json says so. It reads the desk like any page. Right now the desk holds … notes in your vault.

The folder holds three files: plugin.json (what it adds, what it talks to), screen.html (this page), blocks.js (a block a note can carry: three backticks, desk, then hello AAPL). Copy the folder, rename it in plugin.json, change what you like, and bring it in from Settings. Every address the desk answers is listed at /agent.
