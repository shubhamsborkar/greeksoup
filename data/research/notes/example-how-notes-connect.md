This is an example project, here so the screen is not empty. Delete it whenever you like; it is one file in the data/notes folder.

A **project** is a note like this one whose type is Project. The names it lists are the names in the project, and every note that says it belongs to this project shows up under it. The three notes below belong here: [[Example: a call note]], [[Example: a risk note]] and [[Example: a commodity note]], the last one about a commodity rather than a listing.

Write $AAPL anywhere in a note and the note appears on Apple's page. Link to another note with double brackets, and both notes show the link. Open the folder in Obsidian and the same files, links and names are there.
